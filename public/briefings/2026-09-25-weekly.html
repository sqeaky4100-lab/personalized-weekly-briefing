ChatGPT Voice can now use plugins—and Work can keep going after you stop speaking

Voice can use the plugins and connected apps already available to your account on web, iOS and Android. In Work, it can also create documents, presentations or spreadsheets and use a browser; if a job is unfinished when the call ends, it can continue in text.

Free and Go users can use supported plugins in Voice Chat; Voice in Work requires both Voice and Work access. Existing permissions and usage limits apply, and sensitive actions still require on-screen—not spoken—approval.

OpenAIPersonal financeSep 21

ChatGPT Finances adds Experian credit-score tracking and monitoring

Eligible users can connect an Experian report and VantageScore 3.0, ask what is affecting the score and receive alerts for changes such as a new inquiry, account or address. The report updates monthly and the Experian connection is separate from bank accounts connected through Plaid.

Rolling out to U.S. Plus and Pro users on web, iOS and Android, so some eligible accounts may not see it yet. It is a soft inquiry, but lenders may use different bureaus or scoring models; enter identity details only in Experian’s verification form, not in chat.

AnthropicClaude Opus 5.5Sep 22

Claude Opus 5.5 targets the same class of work with lower cost and faster output

Anthropic says Opus 5.5 performs at Fable 5.1’s level on most work while costing about 40% less than Opus 5 on typical workloads. It lists $4 per million input tokens, $20 per million output tokens, $0.20 cache reads and output more than 30% faster than Opus 5.

Available across Claude platforms and major clouds. The performance and savings figures are vendor tests and early-customer reports, so validate them on your own document set before changing a production workflow.

PerplexityCloud APISeptember

Perplexity Fast Search cuts lightweight web checks to $1 per 1,000 calls

Perplexity added search_type: "fast" for lower-latency web retrieval, priced at $1 per 1,000 Search API requests instead of $5 for standard web search. Its Agent API fast preset now uses the same path, with web-search calls dropping from $2.50 to $1 per 1,000 and Perplexity reporting about 800 ms lower latency.

This is a paid cloud API, not a free-tier consumer-chat feature; Agent API model tokens are billed separately. Use standard web search for rare, difficult or ambiguous questions, and note the temporary SDK workarounds in the docs.

U.S. snapshotRates + housingSep 16–23

The Federal Reserve raises rates to 3.75%–4.00% as inflation stays broad

The FOMC unanimously raised its target range by a quarter point on September 16. This week, several Fed officials said persistent inflation—not only energy or tariff shocks—supported the move, reinforcing the risk that borrowing costs remain elevated.

Policy signals can change with new data, and mortgage rates do not move one-for-one with the federal funds rate. Treat this as a decision input, not a timing forecast for buying property.
