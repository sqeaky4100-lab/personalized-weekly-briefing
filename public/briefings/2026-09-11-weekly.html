OpenAIAudit workflowSep 10

ChatGPT can now turn connected business data into an interactive report

The new Data plugin in ChatGPT Work and Codex can investigate changes and build interactive dashboards from connected business data. On the same day, Box, Dropbox and SharePoint joined Google Drive in ChatGPT Library, letting web users work across source folders without repeated uploads and follow citations back to the files.

Rolling out on web; plan, admin, connector authorization and existing file permissions apply. Mobile Library support is still to come.
Source: OpenAI release notes ↗

One cloud workflow can now find the PBC folder, query the connected data, explain a variance and produce a reviewable visual deliverable. That reduces upload churn, but inherited permissions are not a substitute for engagement-level scoping.

For your TB/GL and audit dashboard work, this is the closest productized path yet from authorized source files to a source-linked, interactive deliverable.

Use @Data with the selected TB/GL folder. Reconcile beginning balance + activity to ending balance; flag accounts over my threshold; build an interactive variance dashboard by account and month; cite every figure to its source file; list unresolved mapping or completeness questions separately. Do not infer missing values.

OpenAIFinancial servicesSep 10

ChatGPT for Financial Services makes traceability—and firm templates—first-class

OpenAI launched a tailored ChatGPT Work experience with GPT‑6 Astra, built-in premium financial data, granular source tracing and interactive charts. Admins can publish Excel, Word and PowerPoint templates, while compliance teams can export supported workspace logs.

Available only to eligible financial institutions via sales. Initial product focus is investment banking and equity research—not external audit.
Source: OpenAI ↗

The important design signal is the bundle: licensed data, evidence highlighting, standardized output templates, role-based controls and logs in one governed workspace. OpenAI says 50+ connectors sit in the wider ecosystem.

Even without eligibility, this is a useful blueprint for an audit AI control stack: authoritative inputs, reproducible calculations, source-level review, locked templates and retained activity evidence.

Draft a one-page control matrix for an AI-assisted financial analysis workflow. Cover: approved data sources, completeness checks, recalculation, source-level citations, template/version locking, reviewer sign-off, exception handling, access by role, retention, and log export. Separate preventive, detective, and governance controls.

GoogleFrontend + agentsSep 2

Gemini 3.8 Flash targets long-horizon agent work at Flash pricing

Google says Gemini 3.8 Flash improves on 3.7 across software engineering, agentic tasks and multi-step professional reasoning while keeping the introductory price at $0.75 per million input and $3.75 per million output tokens. Perplexity’s Agent API added the same model in September, including a lower cached-input rate.

Google’s performance claims are benchmark-based; validate on your own artifacts. The separate Cyber variant is restricted to trusted defenders.
Source: Google ↗

A cheaper frontier model can now serve as the repeatable QA pass after a stronger model builds the artifact—especially where the task is a long checklist rather than a single answer.

For your portable HTML and property-site work, this creates a plausible low-cost second-review layer for mobile layout, keyboard access, state persistence and data-label consistency.

Review this web artifact as an independent QA agent. Test at 390px and desktop widths; keyboard-only navigation; light/dark contrast; reduced motion; empty/error states; persistent favorites; chart labels vs source data; and every outbound link. Return only: blocking defects, reproducible steps, expected result, and the smallest safe fix.

PerplexityCloud MCPSeptember

Perplexity’s remote MCP now signs into claude.ai with OAuth

Perplexity’s hosted MCP endpoint now supports OAuth, so compatible cloud clients such as claude.ai can connect through a Perplexity sign-in instead of a pasted API key. You choose the API organization to bill during sign-in; API keys remain available for clients without OAuth.

This simplifies authentication, not cost: usage bills the selected Perplexity API organization. Availability also depends on your MCP client and workspace policy.
Source: Perplexity docs ↗

The remote endpoint is https://api.perplexity.ai/mcp. OAuth removes the secret-copying step and makes organization selection explicit during connection.

This fits your cloud-only integration preference and gives a clean research connector for recurring runs without storing a long-lived key in every workflow.

In claude.ai, add https://api.perplexity.ai/mcp as a custom remote connector, sign in with Perplexity, and select the intended billing organization. First test: find primary-source updates from the last 7 days, return title/date/direct URL, and omit any claim that cannot be tied to a source.

World snapshotHealthSep 11

Congo’s fast-growing Ebola outbreak reaches a seventh province

The outbreak has reached Sud-Ubangi in western Democratic Republic of Congo, the first confirmed westward spread, with a rare Bundibugyo strain detected there. AP reports 6,942 cases and 3,349 deaths; conflict, displacement, staff shortages and limited strain-matched vaccine options are complicating containment.

Counts are changing quickly. This is a regional public-health emergency; use WHO or Africa CDC updates for travel or operational decisions.
Source: AP · data via officials/WHO ↗

The geographic jump matters more than the headline count: spread from the conflict-hit east to the west increases cross-border risk toward Central African Republic and potentially South Sudan.

This is the one world development this week worth keeping on your situational-awareness list, especially for travel, supply-chain or multinational client exposure.

For decisions, bookmark the official situation reports and record the report date beside every figure; do not reuse today’s case count as a standing fact.
