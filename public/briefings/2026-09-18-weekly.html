ChatGPT arrives inside Microsoft Word

ChatGPT’s Microsoft add-in now supports Word alongside Excel and PowerPoint. From the sidebar it can draft from notes, summarize a document, revise selected text, and adjust headings or formatting; the Marketplace listing also says it can bring connected sources into the Word workflow.

Available on all ChatGPT plans, including Free, but token limits, Microsoft 365 environment, region and admin controls apply. Add-in chats do not sync to ChatGPT history, and Memory is unavailable.

Official Marketplace listing ↗

The assistant now works against the open document and selected text instead of requiring a paste-export-repaste loop. OpenAI warns that important numbers, citations and claims still require primary-source verification.

This is well suited to your short experience writeups, status memos and workpaper conclusions: the source draft stays visible while you tighten wording and formatting, but the audit evidence remains outside the model’s authority.

Review only the selected conclusion paragraph. Preserve every amount, date, person, assertion and cross-reference exactly. Improve clarity and concision for an external-audit workpaper. Then list any statement that appears unsupported or internally inconsistent; do not silently correct it.

Multiple-account plugin connections expand beyond Google’s core apps

ChatGPT now lets you connect multiple accounts to plugins beyond Gmail, Google Calendar and Google Contacts. That means personal and work identities can live in one conversation without signing out and reconnecting each service.

Available across web and mobile on all ChatGPT plans. Each account retains its own authorization and underlying service permissions; workspace controls may still restrict a plugin.

The earlier multi-account support was limited to three Google services; the September 17 update broadens the pattern to plugins generally.

You actively use separate Gmail identities for formal communications and personal property work. The useful part is less re-authentication; the control risk is asking the right question against the wrong account.

Before using any connected account, state the service and account identity you intend to search or act through. Keep firm/audit data and personal/property data in separate tasks. If the selected identity is ambiguous, stop before reading or sending anything.

Custom GPT migration is starting—and custom actions will not come along automatically

OpenAI plans to retire custom GPTs and move their reusable instructions into plugin skills. Enterprise migration was targeted for September 17; new custom-GPT creation is planned to end September 25, with retirement scheduled for December 11.

Dates are planned and may vary by plan/workspace. Custom actions do not transfer automatically; prior chats and conversation starters may not copy, and the selected model does not carry over.

Official migration FAQ ↗

A migrated GPT becomes read-only until retirement. Its replacement plugin starts private, and access must be re-shared and tested; public-GPT access does not guarantee access to the replacement.

Any reusable audit, property-brief or HTML-generator GPT should be inventoried now. The highest-risk break is a hidden custom action that previously sent data or called a workflow.

Create a migration inventory with columns: GPT name, creator/workspace, business purpose, users, instructions captured, reference files, custom actions, replacement app/MCP, three regression prompts, expected output, owner, and tested date. Flag every custom action as “rebuild required.”

Perplexity Projects can now store a remote MCP connection once

Perplexity’s Agent API added custom connectors for remote MCP servers. A Project administrator registers the server URL and credential once; later runs reference a connector ID instead of resending the MCP secret every request.

Available to all Projects, but this is API infrastructure rather than the consumer Perplexity chat. It supports API-key or no authentication over Streamable HTTP or SSE; Agent API usage remains billable.

Perplexity stores connection settings and credentials at the Project level. Managed connectors currently include GitHub, Slack, Google Drive, Datadog, Linear and Notion; a custom connector can point at another remote MCP server.

This fits your preference for cloud-hosted tools and makes a Google-Sheets state service or property-listing MCP reusable across scheduled runs without repeating a large tool definition or embedding the MCP credential in each script.

Pilot one read-only connector first. Expose only: get_state(run_key), upsert_state(run_key, last_seen_id, checked_at), and list_recent_changes(since). Keep large history in Sheets; return only changed rows plus stable IDs. Measure input tokens before and after deferred tool discovery.

Iran claims a tanker strike as Hormuz traffic remains roughly 90% below prewar levels

Iran said it struck the Togo-flagged tanker Trend over an allegedly unauthorized passage; AP could not independently confirm the claim. A separate tanker was reported hit by an unknown projectile, with its crew safe and fire extinguished, while military-facilitated traffic through the strait remains sharply reduced.

The incident picture is still developing. Reuters separately reported oil-linked inflation concerns, a Federal Reserve rate increase and the largest weekly global-equity-fund outflow in nine months.
